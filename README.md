# Snake Game 🐍
A Python-based Snake Game developed using Pygame, where players control a snake to collect food, grow longer, and avoid collisions.

## Project Overview
Snake Game is a Python-based arcade game developed using Pygame. The player controls a snake that moves around the screen, collects food, and grows longer while avoiding collisions.

## Features
- Smooth snake movement.
- Food collection system.
- Snake growth after eating food.
- Score tracking.
- Collision detection.
- Game over functionality.

## Technologies Used
- Python
- Pygame

## Installation

Install Pygame using pip:

```bash
pip install pygame
```

## How to Run
1. Install Python on your computer.
2. Install the Pygame library.
3. Download or clone this repository.
4. Open the project folder in VS Code.
5. Run the following command:

```bash
python snake_game.py
```

## Project Purpose
This project was developed to practice Python programming, game development, event handling, collision detection, and working with the Pygame library.
